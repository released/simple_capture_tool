# Simple Capture Tool 使用手冊

**繁體中文（預設）** | [English](USER_GUIDE_EN.md) | [回到專案首頁](../README.md)

程式首次啟動預設使用**繁體中文**。如需英文介面，可至「設定 → 一般設定 → 語系」選擇英文並儲存；之後啟動會沿用已儲存的語系選擇。

## 開始使用

1. 使用 Windows 10 1903 或更新版本，x64。將工具放在可寫入的資料夾，執行 [SimpleCaptureTool.exe](../build/SimpleCaptureTool.exe)。
2. 程式直接常駐系統匣。按 `Ctrl+Shift+X` 擷取矩形區域，或從系統匣右鍵選單選擷取模式。
3. 放開滑鼠後進入最大化的編輯器，加入文字、箭頭、圖形或螢光筆。
4. 按 `Ctrl+A`、`Ctrl+C` 複製整張合成圖；按 `Ctrl+S` 自行選擇資料夾及檔名。圖片不會自動存檔。

首次儲存使用 Windows Downloads，預設格式為 JPG；成功存圖後優先使用上次儲存資料夾。關閉圖片或編輯器會直接丟棄未儲存的 RAM 圖片；需要暫時保留時請最小化或使用「縮到系統匣」。

## 排版、樣式與局部編輯

以下命令可從最上方「編輯」選單使用，也可按 Ctrl+Shift+P 搜尋名稱，或在自訂常用加入相關群組項目。

- **重新排版選取物件**：選取 2～64 個可見、未鎖定的物件單位，設定橫列／直列／網格、欄數 1～64、間距 0～4096、順序與起點。群組算一個單位，群組內相對位置保留；圖片不重取樣。畫布不足時向右／下增加白色空間，整次操作可一次復原。這是一次性排版，不會在之後移動物件時自動重新排列。
- **圖片物件還原原尺寸**：選取一張未鎖定、未群組的圖片，將外框寬高還原成目前素材裁切範圍的像素尺寸，保留左上位置、裁切、遮罩及素材。必要時向右／下擴充畫布，可復原。這與「100% 檢視」不同；曾經點陣化旋轉／套用效果的圖片，以目前替代素材為準。
- **工具樣式預覽**：先用「儲存工具樣式」建立命名樣式，再開啟縮圖選擇器，可依工具篩選。縮圖是背景產生的示意內容，不保存文件文字或截圖。套用到相容的單一未鎖定物件時保留內容與位置；矩形與路徑筆刷需為相同模式，其他情況設定後續繪圖工具。沿用最多 32 個樣式及目前預設樣式保存方式，不新增固定功能列。
- **重複上次圖片效果／調整上次圖片效果**：在目前工作區內跨分頁共用上次成功套用的支援效果參數，包括一般調色、Gamma、復古褐色、替換顏色、色階縮減及圖片物件色彩效果。重複會使用當前圖片／選區；調整會重新開啟參數。選區限定效果需要目前有效選區，不沿用舊選區位置。需要合併標註或合成圖片素材時仍會詢問，預設「否」。每次套用可一次復原；相同結果不增加步驟。這不是巨集或批次工作流程，關閉工作區即清除記憶。
- **切換路徑掃選物件**：開啟後按住滑鼠畫過要選取的物件外框，放開後選取經過的物件／群組。以外框判斷，不是圖片透明輪廓辨識；隱藏物件忽略，含隱藏成員的群組不納入。最多 4096 點，Esc 取消；Ctrl／Shift 點選維持原操作。這是物件選取，不會建立像素套索、不改圖片或新增復原步驟。
- **模糊筆刷／馬賽克筆刷**：沿滑鼠路徑塗畫，從「效果筆刷設定」調整直徑 1～128 像素與強度 1～100。放開後保留可編輯筆跡並可連續畫下一筆，每筆可復原；每筆最多 65536 點。一般模糊／馬賽克仍為矩形，螢光筆仍為矩形。筆刷效果受下方內容影響；移動或改動底下物件時會重新合成。模糊／馬賽克不等於安全移除資訊。
- **建立圖片圖卡**：選取單一未鎖定、未群組的圖片，設定留白 0～512、框線 0～128、陰影 0～60 及顏色。程式產生背景圖片物件，將原圖移入留白並分組，保留原圖素材與其他標註。整組可移動、縮放，一次復原撤回；要各別修改可先取消群組。圖卡是一般群組，不是持續連動的參數化效果。
- **匯出選取標註為 SVG**：明確選擇檔名，輸出選取物件在畫布內的部分，不含截圖底圖。支援圖形、筆跡、箭頭及一般文字的向量路徑；文字轉為輪廓，外部軟體不會把它當成可重新輸入的文字。圖片、陰影、虛線及複雜文字等以內嵌 PNG 備援，輸出前會詢問；Multiply 螢光筆可能使整組以 PNG 合成。馬賽克、模糊等依賴底圖的物件不支援。最多 256 個物件，SVG 限 64 MiB、單個內嵌 PNG 限 48 MiB，不包含外部檔案連結、腳本或字型。原圖、儲存路徑、剪貼簿及復原紀錄保留。

大型排版、圖卡與筆刷有工作緩衝區上限，超限會拒絕，不會偷偷縮小素材。SVG 中的位圖仍是位圖，放大不會增加截圖細節；需要保留完整可編輯內容時使用 `.sctproj`。

## 素材重用與選區工具

以下命令都可從最上方「編輯」選單使用，也可在「自訂常用」加入對應群組內的項目，保留自己的顯示順序。

- **儲存 → 匯出選取物件為透明 PNG**：選取標註或群組，指定檔名後，只輸出選取物件在畫布內的可見部分及透明邊距，不含截圖底圖或其他物件。支援文字、圖形、箭頭、畫筆、圖章及圖片；馬賽克、模糊等需要底圖像素的工具不支援單獨匯出。此操作不修改原圖路徑、未儲存狀態、剪貼簿或復原紀錄。只讀匯出可包含鎖定物件。
- **標記 → 自訂 PNG 素材庫**：加入自己的 PNG、重新命名或移除收藏，最多 32 項。縮圖在背景載入。「儲存素材庫」保存索引；「儲存並插入」保存索引並以原始像素尺寸插入目前圖片，畫布不足時向右／下擴充，切為 100% 顯示，一次復原即可撤回。取消只放棄尚未儲存的索引變更；移除收藏不刪除原檔。索引保存在 INI，不複製素材；工具資料夾內使用相對路徑，外部使用完整路徑。搬移電腦時請一併攜帶素材。檔案遺失會顯示失敗狀態。每張 PNG 的編碼檔案及解碼像素各限 64 MiB；此入口直接讀取 PNG 像素，不另套外部圖片匯入的 ICC／方向轉換。
- **選取 → 交集像素選區**：先建立選區，再以矩形、橢圓或套索圈選，保留兩者重疊部分及原有孔洞。沒有既存選區時結果為空。仍可切回取代、加入或減去模式；選區本身不修改圖片或增加復原紀錄。
- **選取 → 切換選區色彩預覽／選區預覽顏色／透明度**：以色罩標示選取的像素，孔洞維持未選取。顏色及透明度 1～200 可調，每個 RAM 分頁預設關閉。色罩只顯示在編輯器，不會存入專案、圖片或剪貼簿，也不改變標註透明度。
- **選取 → 依圖片透明度建立選區**：選取單一未群組的圖片物件，設定透明度門檻 1～255。依該圖片目前裁切、外形遮罩、縮放與整體透明度，在畫布內建立二值像素選區。這是選區操作，允許鎖定圖片且不修改原圖／素材。它不是保留漸層透明度的柔邊遮罩。
- **箭頭 → 連接箭頭錨點**：選取單一未鎖定、未群組且已連接物件的直線箭頭。起點與終點可各選中心、自動外框交點或左／上／右／下側中點。預設中心保留舊版行為；自動交點使用物件矩形外框，並非圖形輪廓辨識。目標移動／縮放時會跟隨，一次復原可還原；不提供自動繞障礙路徑。
- **圖形 → 線條／填色透明度**：選取單一未鎖定、未群組的矩形、圓角矩形、橢圓、多邊形或對話框，分別設定 0～255。兩者仍會乘上物件原有的整體透明度；0 為透明，255 保留原有強度。對話框文字沿用整體透明度。專案及工具樣式會保留設定，操作可復原。
- **影像 → 圖片物件色彩效果**：選取單一未鎖定、未群組的圖片物件，選擇 Gamma、復古褐色、顏色替換／轉透明、色階縮減、灰階或反相。參數範圍與全圖同類效果相同。確認前會詢問，預設「否」；套用時只把此圖片目前裁切、遮罩、調色及透明度合成到替代素材，底圖與其他物件保留。一次復原還原原始素材及設定；相同像素結果不增加復原紀錄。這不是可持續調參的濾鏡堆疊，重複取樣可能降低品質。

選區／單張圖片處理仍受畫布尺寸與工作緩衝區限制，過大的操作會拒絕，不會縮小原圖來套用。素材庫只保存自己選擇的檔案參照，不提供下載或雲端同步。

## 比例擷取、標註與輸出

所有命令都可從最上方「編輯」選單進入，也可在「自訂常用」加入相關下拉群組。

- **擷取比例**：矩形／橢圓區域工具列可選自由、1:1、16:9、4:3 或自訂整數比例（各 1～10000）。可拖曳或調整選區，Ctrl 暫時改為正方形；自由手繪、固定區域和指定視窗不套用比例。比例只保留於當次擷取，正常單區域仍放開滑鼠即進入編輯。
- **對話框尾端**：選取對話框，拖曳尾端的小控制點；文字框位置不變。亦可從「圖形」輸入尾端座標，或恢復預設尾端。移動／縮放框時尾端會一起調整，操作可復原。
- **螢光筆混色**：在「繪圖」選一般或色彩增值（Multiply）。色彩增值會保留底下黑色文字；仍是矩形塗色，透明度與顏色可調整，既有螢光筆也可修改。
- **拖曳連續複製**：先選取未鎖定的物件或群組，在「物件」開啟此模式，再拖曳物件。拖曳中每按一次空白鍵，會在當前位置留下一份獨立副本；原物件繼續跟隨滑鼠。放開後整次操作可一次復原，Esc 或失去滑鼠擷取會取消整次操作。每次最多留 64 份，關閉模式或切換其他工具可恢復一般操作。
- **單一圖片任意角度旋轉**：選取一張未鎖定、未群組的圖片，在「旋轉」輸入 -180～180 度。確認後只重取樣這張圖片，保留中心、擴充透明邊緣；目前裁切、外形遮罩、顏色調整與透明度會一起套入替代素材。其他物件及底圖不變，一次復原可取回原素材。反覆重取樣可能降低畫質。
- **選區框線**：先建立像素或裁切選區，在「選取」指定 1～128 像素、內側／外側與顏色。結果是一個可移動、可刪除的透明圖片物件；外框超出畫布的部分會裁掉，原選區及底圖不變。
- **縮放匯出／複製**：分別在「儲存」及「剪貼簿」設定百分比（1～400%）、指定寬度等比例，或指定寬高。匯出仍會詢問位置與檔名，複製會產生縮放後的合成圖片；原畫布、儲存路徑、未儲存狀態與復原紀錄不變。一般 Ctrl+A、Ctrl+C 維持原尺寸整張圖面。尺寸及預估背景處理緩衝超限會拒絕，不會偷偷縮圖。
- **手動批次匯出**：在「儲存」選擇目前 1～64 張 RAM 分頁，指定資料夾、JPG／PNG／BMP 和各張檔名。可取消勾選、修改名稱後再匯出；同批重名或已存在的檔案會被拒絕。背景逐張處理並列出成功與失敗結果，部分失敗不會回滾已成功輸出，也不會把分頁標記為已儲存。成功後，下次存圖優先使用這個資料夾。

## 選取、文字框與外形遮罩

所有功能都可從最上方「編輯」選單進入，亦可在「自訂常用」加入對應群組內的項目；既有的常用排序及第二層選項不會被改寫。

- **選取相同類型／線條色／填色**：先選一個參考物件，再使用「選取」群組。只比對目前分頁可見物件；同群組成員會一併選取，不會合併圖片或建立復原紀錄。線條色也適用文字的主要顏色；圖片素材沒有線條色，未填色的圖形沒有填色，不會比對未使用的色彩欄位。
- **文字框與行距**：選取單一未鎖定、未群組的文字或對話框物件，在「文字」設定內距 0～256 像素、行距 50～300%，以及固定寬度自動增高。自動增高在編輯文字及完成輸入時依內容調整高度，保留字型、局部文字格式與框的左上位置。固定高度模式中超出可用內框的內容會裁掉。
- **圖片外形遮罩**：選取單一未鎖定、未群組的圖片，在「圖片」選擇矩形、圓角或橢圓。圓角半徑可設定，矩形可恢復原外形。此操作只裁出顯示範圍，原素材與既有圖片裁切都會保留，並可復原。
- **選區羽化成新圖片**：建立像素選區或裁切選區，從「選取」輸入羽化半徑 0～100 像素。工具將當前合成畫面選區的柔邊結果開成獨立 RAM 圖片，原圖與剪貼簿不變；半徑 0 為一般取出選區。結果以透明度表達邊緣，需 PNG 或專案才能保存透明度。

外形遮罩與羽化是視覺編輯，不能清除原始敏感資訊；可編輯專案仍可能包含遮住的素材。

## 筆跡、任意路徑與連接箭頭

- 在「繪圖 → 平滑選取筆畫」處理單一未鎖定、未群組的自由畫筆，強度 0～100。這是繪製後的明確操作，保留第一／最後點及可編輯資料，一次復原可還原原始路徑；強度 0 不修改。
- 「箭頭 → 箭頭端點樣式」可各自指定起點、終點為無、開口箭頭、實心箭頭、圓點或橫線，尺寸 0 表示隨線寬自動計算。選取現有箭頭可修改；未選物件時設定新箭頭。拖曳直線或曲線箭頭節點仍可獨立改變角度。
- 「圖形 → 自由多邊形／逐點折線」以左鍵逐點加入，移動滑鼠預覽下一條線，雙擊或 Enter 完成，Backspace 移除上一點，Esc 取消；最多 64 點。多邊形至少 3 點，折線至少 2 點。完成後可選取並拖曳各節點。這個操作不會取代原本的規則多邊形。
- 「圖形 → 切換從中心繪製／縮放」只作用於目前 RAM 分頁，預設關閉。開啟後可從中心向兩側繪製矩形、橢圓等圖形，或對稱縮放既有物件；Shift 的限制比例仍可使用。新圖形會限制於畫布內；此選項不影響箭頭節點、裁切、像素搬移及自由畫筆。
- 選取兩個可見圖片、圖形或文字物件，再使用「箭頭 → 連接兩個物件」，依層級順序選擇方向。直線箭頭連接兩物件中心，移動／縮放物件時跟隨，並可一起復原。它不會自動避開其他物件或繞線。
- 「解除箭頭連接」保留箭頭目前位置；直接拖曳某端點則只解除該端。刪除或隱藏目標時，對應端停在原位置並解除連接。複製一整組物件保留其內部連接，只複製箭頭則解除外部連接。若連接箭頭已鎖定，需先解鎖才能移動會牽動它的目標。

`.sctproj` 與可編輯物件格式保留這些設定；可讀取較舊專案，使用這些功能儲存的專案請以目前或更新版本開啟。

## 樣式、圖片素材與精準編排

- 選取一個物件，從「編輯 → 工具樣式 → 複製物件樣式」複製格式；切換分頁後選取相同類型的物件，再貼上樣式。可一次套用到多個相同類型的物件。文字內容、位置、群組及局部文字格式保留；鎖定物件需先解鎖。
- 「編輯 → 圖片 → 替換圖片內容」適用於單一未鎖定、未群組的圖片物件。可選等比例縮入原範圍（左上對齊）、延展或置中裁切填滿；後兩者保留原外框尺寸，層級與樣式保留。
- 同一分類的「圖片亮度／對比」只影響該圖片物件，可重開修改或切換停用效果，無需合併其他標註。替換、調整及切換效果各為一次復原操作。
- 「箭頭」包含直角折線箭頭，可選一個／兩個轉折、先水平／先垂直。拖曳端點改位置；一個轉折的節點會連動兩端，兩個轉折的節點會移動中間線段，保持直角。
- 「檢視 → 畫布格線設定」控制目前分頁的格線顯示、間距與拖曳吸附。預設關閉，吸附以物件外框左上為基準；同時開啟物件吸附時優先使用較近目標，拖曳中按 Alt 可略過吸附。格線過密時暫不顯示，不影響文件或輸出。
- 「尺寸 → 調整大小」可選最近鄰（像素圖）、雙線性或高品質雙三次（預設）。圖片素材維持可編輯，選取的取樣方式也用於縮放後的圖片物件。

## 複製修補與隱私遮蔽

在「橡皮擦」群組選擇「複製修補筆」。先 Alt＋左鍵點取樣點，或使用「設定修補取樣點」後點一下，再到目的位置拖曳塗畫。線寬決定筆徑，透明度控制疊加強度。每筆固定取樣該筆開始前的合成畫面，取樣超出圖片的部分不塗畫；結果是可移動、縮放及復原的透明圖片物件。這是指定來源的像素複製，不會自動推測或生成背景。

「遮蔽 → 隱私馬賽克」使用選定顏色產生不透明色塊，不讀取遮蔽範圍內的原始像素；一般馬賽克仍會平均原像素。需要純色遮住內容時可使用實色遮蔽。這些效果只保護輸出的合成圖；`.sctproj` 與物件範本可能保留原始素材，不能當作已清除原始敏感資料的圖片分享。

## 水平拼接與圖片比較

從「截圖 → 水平手動拼接」選取視窗及範圍，向右捲動後按 F8 擷取下一張。無法可靠判斷重疊時，調整重疊像素並按套用；可復原上一張，按完成才送入編輯器。垂直手動拼接維持原有操作；水平模式不會自動捲動或處理二維拼圖。

開啟兩張 RAM 圖片後使用「編輯 → 比較兩張圖片」。RGB 容差預設 0，Alpha 仍精確比較；圖片 B 的 X／Y 位移預設 0，可輸入正值（向右／下）或負值（向左／上）手動對準。超出另一張的範圍仍標為不同，兩張來源圖片都不會修改。

## 啟動與系統匣

執行 `build\SimpleCaptureTool.exe` 後，程式會常駐系統匣。右鍵選單可擷取畫面、開啟主視窗、調整設定或結束程式；雙擊可開啟視窗。每個 Windows 工作階段只允許一個正常執行的實例。

主視窗及編輯器上方都有「檔案／截圖／設定」選單；編輯器另有完整的「編輯」分類選單。常用工具列只提供捷徑，自訂隱藏按鈕不會刪除功能。

關閉圖片、編輯視窗或結束程式會直接丟棄未儲存圖片。要暫時離開但保留圖片，請最小化或使用編輯器的「縮到系統匣」，不要按關閉。

## 螢幕擷取

### 選擇範圍

- 全螢幕：擷取所有螢幕；也可選擇目前螢幕或單一螢幕。
- 區域：矩形、橢圓、自由手繪或多區域。
- 視窗：指定視窗，可依擷取選項選內容區或子控制項。
- 固定區域：使用固定寬高；可重複上次範圍或使用命名區域預設。
- 延遲：設定倒數，供選單、提示及其他需要準備時間的畫面使用。

單一區域選取放開滑鼠後即進入編輯器。需要先調整範圍時，按住 Shift 再放開滑鼠，調整後按 Enter；多區域選區需確認。

圈選矩形或橢圓時按住 Ctrl，可限制為正方形或正圓；多區域中的矩形也支援。這不會改變固定區域、指定視窗或自由手繪選區的操作。Ctrl 限制比例與 Shift 保留選區微調可同時使用。

滑鼠從截圖工具列或其操作提示的上方靠近時，整排往下避讓；從下方靠近時則往上避讓，露出原位置的畫面。游標到螢幕頂端時，工具列會在游標下方；到螢幕底端時，工具列會在游標上方。移開後保持新位置，停住時不會來回跳動。按住 Alt 可固定工具列來操作按鈕或下拉選單；選單展開時不會移動。空間不足時可用 Tab 隱藏工具列。

選區中的操作：

| 操作 | 用途 |
| --- | --- |
| `Enter`／`Esc` | 確認／取消 |
| `Tab` | 隱藏或顯示選區工具列 |
| 按住 `Alt` | 暫停工具列避讓，以便操作控制項 |
| 方向鍵／`Shift+方向鍵` | 移動 1／10 像素 |
| `Ctrl+方向鍵` | 調整選區大小 |
| `Space` | 加入目前範圍並繼續選取多個區域 |

桌面與區域模式從凍結畫面擷取；指定視窗及捲動模式使用目標視窗的即時畫面。跨螢幕座標可為負值。游標、放大鏡、格線、選區外變暗等選項可從「設定 → 擷取選項」調整。

### 擷取到目前圖片與可編輯游標

若要把新截圖加入手上的說明圖片，請在來源分頁選「編輯 → 截圖 → 擷取區域並插入目前圖片」。圈選後以原始像素尺寸插入該頁，可再移動或縮放；畫布不足時向右／下擴充，整次操作可一次復原。若等待期間原頁變更或關閉，會取消插入，請重新操作。

在「設定 → 擷取選項」勾選「截圖游標保留為可編輯物件」，並啟用一般設定中的游標擷取，單次截圖的游標會成為可移動、縮放或刪除的圖片物件。此選項使用可見桌面擷取；指定視窗被其他視窗遮住時也會擷取遮住它的畫面，請先露出目標。游標形狀及位置取自擷取當下，移動物件不會重新反相背景。此選項不適用捲動截圖。

### 捲動截圖

先選目標視窗，再框出可捲動內容區。避開固定頁首／頁尾、捲軸、動畫及不隨內容捲動的區塊。自動捲動需目標程式接受標準滾輪訊息；按 Esc 可停止並保留目前拼接內容。

若無法可靠對齊，使用「手動捲動拼接」：自行捲動目標，按 F8 或視窗按鈕擷取下一張。重疊高度代表前後兩張重複的列數，可調整後套用，或復原最後一次拼接。完成前請檢查接縫。

## 標註與物件編輯

截圖會加入最大化的共用編輯工作區；每張圖片有獨立分頁、物件、路徑與復原狀態。

- 畫筆沿滑鼠路徑繪製；螢光筆為可選色的半透明矩形。
- 文字支援字型、字級、粗體、斜體、底線、對齊，以及透明背景或不透明底色。輸入完成可點空白處或按 Ctrl+Enter；Esc 取消草稿。雙擊文字可重新編輯。
- 直線箭頭的頭尾可各自移動；曲線箭頭另有兩個控制點調整弧度。
- 數字圖章會接續編號；「標記 → 數字圖章重新編號」可選起始值及建立／上下／左右順序。有選取時只改選取圖章，否則處理所有可見圖章；鎖定物件不會被修改。
- 馬賽克強度滑桿為 1–100%，控制像素方塊大小，不是透明度。
- 一般橡皮擦預設透明擦除，可改用指定顏色。智慧橡皮擦以鄰近不透明像素的代表色修補，並非 AI 內容感知填補；複雜背景請自行檢查。

點擊既有物件可選取、移動、調整大小或修改屬性。空心圖形點外框選取；按住 Alt 可強制在既有物件上繪製。完成文字的點擊只負責提交，不會同時新增下一個文字框。

繪製矩形、圓角矩形或橢圓時按住 Shift，可維持寬高相等；直線與直線箭頭則限制為 45° 的倍數。拖曳既有物件外框的縮放控制點時按住 Shift，可保留原始寬高比；多選物件或群組以整體外框計算。Shift 點擊物件本體仍可增減選取，鎖定物件不會被改動。

在畫布上按右鍵，或以選單鍵／Shift+F10 開啟快捷選單，可使用復原、複製、貼上、物件屬性、群組、鎖定與裁切等常用操作。右鍵點到其他物件時會先選取它；不可用的命令會停用。文字輸入框內保留原生文字編輯選單。

文字輸入中使用滾輪、Shift+滾輪、捲軸或中鍵平移時，輸入框會跟隨畫布上的文字。超出可見畫布的部分會裁切；完全移出時暫時隱藏，草稿仍保留，捲回後可點入繼續編輯。文字框的換行寬度與文件位置不會隨捲動改變。

### 重疊物件、圖片變換與文字搜尋

多個物件重疊時，可在目標位置按右鍵，選「選擇此處重疊物件」，從由上到下的清單選取所需物件；不必先搬走上方物件，也不會改變層級。

選取一個可編輯圖片物件後，「編輯 → 旋轉」內的「圖片物件右轉 90°／水平翻轉／垂直翻轉」只修改該圖片，保留底圖與其他標註。整張圖片的旋轉命令另列於同一分類；鎖定或群組內物件需先解除鎖定／群組。

「編輯 → 文字 → 尋找／取代標註文字」可區分大小寫，尋找下一個符合的可見文字或註解框，取代目前／下一個文字物件中的符合內容，或取代目前頁全部符合內容。取代可一次復原；匹配到鎖定文字時不會部分修改。此功能讀取可編輯物件的文字，不辨識截圖內的文字。

### 多物件與側欄

Ctrl／Shift 點選可增減物件；使用選取工具可拖曳框選，Ctrl+Shift+A 選取物件。Ctrl+A 則是整張合成圖，不是多物件選取。

「物件」提供群組、鎖定、層級、對齊及等距排列。群組視為整體；等距需要至少三個物件或群組。拖移吸附可對齊畫布及其他物件的邊緣／中心，拖曳中按 Alt 暫時略過。

「置於最上層／置於最下層」可一次調整選取物件或群組的層級，保留選取範圍內的相對順序。畫布快捷鍵為 Home／End；文字框、側欄及下拉選單仍保留自己的按鍵操作。鎖定物件需先解除鎖定。

### 重用物件範本

先選取要重用的文字、框線、箭頭或圖片等物件，再用「編輯 → 物件範本 → 儲存選取物件範本」，自行指定 `.sctproj` 檔名與位置。群組會整組保存。範本另建透明底圖，不含原始截圖底圖；選取物件的文字及內嵌圖片素材仍會保存，分享前請檢查內容。

在其他圖片選「載入物件範本」，物件會以原座標及尺寸插入並保持可編輯。畫布不足時僅向右／下增加白色空間，群組編號自動避開既有群組；整次載入可一次復原。儲存範本不會將目前圖片標為已儲存，也不會變更它的圖片或專案路徑。「樣式預設」只保存繪圖樣式，與含內容的物件範本不同。

「編輯 → 檢視」中的「物件／圖層側欄」支援命名、顯示／隱藏、鎖定及拖曳層級；「物件屬性側欄」可輸入座標、尺寸及相容的樣式屬性，按套用或 Enter 完成。側欄可關閉以騰出畫布空間。

切換繪圖工具、側欄分頁，或執行編輯命令、修改樣式與顏色前，會先套用有效的待編輯屬性。輸入無效時會保留欄位並阻止切換，請先修正或按 Esc 取消；直接關閉側欄也會取消尚未套用的屬性。關閉圖片或程式仍依前述規則直接丟棄 RAM 內容。

### 功能列圖示與提示

「筆觸」包含畫筆與螢光筆；「編號圖章」包含數字步驟、符號／游標圖章及編號調整。「尺寸畫布」區分圖片尺寸與畫布大小，「旋轉翻轉」包含旋轉及水平／垂直翻轉，「拼接排版」提供圖片拼接與編排，「物件編排」提供物件屬性、圖層、群組與對齊操作。

編號使用帶數字的圓章圖示，裁切、尺寸、旋轉、拼接、檢視與關閉圖片也有對應圖案。圖示隨目前快捷動作更新；主圖示重複目前動作，下箭頭選擇其他同類功能。滑鼠停留可查看完整名稱、目前動作與同群組選項，不必先打開選單。命令搜尋也接受功能列簡稱。完整選單與自訂常用保留完整名稱，顯示順序仍由自己的設定決定。

### 顏色與樣式

「顏色」提供色盤、自訂顏色、HEX、收藏／最近顏色、圖片吸色及螢幕取色。螢幕取色顯示凍結桌面與放大預覽，左鍵／Enter 套用，右鍵／Esc 取消；圖片吸色只讀目前圖片。

選取物件後改色會套用到選取範圍，鎖定物件除外；沒有選取時設定後續繪圖色。「樣式預設」可命名儲存工具樣式，保留顏色、線寬、字型等設定，不包含圖片內容或文字。

功能列的「線寬」可直接輸入 1～128 像素，或用旁邊上下箭頭、欄位內的上／下鍵每次增減 1。輸入後按 Enter 或離開欄位套用，Esc 取消；Ctrl+S 也會先套用數值再儲存。無效或超出範圍的值會還原。修改單一未鎖定物件可一次復原，輸入每一位數字不會各自增加復原步驟；沒有選取物件時設定後續繪圖。矩形馬賽克不使用線寬，路徑馬賽克筆刷則可調整筆徑。

### 局部文字格式與多邊形

雙擊文字或註解框後，選取要調整的字元，再從「文字」群組選擇「選取文字字型／字級／顏色／粗體／斜體／底線」；也可清除選取字元的格式。一般貼上文字只接受純文字，避免帶入其他文件的物件。關閉文字編輯後仍可再次雙擊修改，輸出與專案會保留局部格式。每個文字物件最多 512 個格式區段；局部格式文字的外框寬度上限約 32 像素。字型仍需安裝於使用的電腦。

從「圖形」選擇三角形、菱形、五邊形或六邊形，再拖曳建立；可設定線條、填色與陰影，並透過既有物件操作移動或縮放。側欄直接替換整段文字會回到統一文字格式；套用整個物件的工具樣式也會套用統一格式。

## 多圖、畫布與剪貼簿

「編輯 → 開啟 → 複製可編輯分頁」建立目前頁的獨立副本，文字、圖形、群組及圖片物件仍可編輯。副本是未儲存的新頁，有自己的後續復原紀錄；不會改變來源頁及其儲存路徑。

### 像素選區

在「編輯 → 選取」選擇矩形、橢圓或套索像素選區。套索沿滑鼠路徑圈選，放開後封閉；「增加像素選區／減去像素選區」可合併不連續區塊或挖空，選「新選區取代舊選區」恢復一般模式。

複製、剪下、刪除、建立新圖片及選區內效果會保留形狀外的像素。拖曳選區內部可搬移內容，放開完成並保留為可編輯圖片物件；透明角落與空洞會保留。涉及已有標註的像素剪下、刪除或搬移時會先詢問合成，鎖定物件不會被合成修改。PNG 可保存透明選區，JPG 等格式會填入白色背景。Esc 或取消選取可離開選區；螢光筆仍使用矩形。

### 依顏色選區

「選取」群組的「魔術棒」只選取點擊位置相連的相近顏色；「依顏色選取」包含整張合成圖中相符的區域。先設定 0–255 的容許差，再點擊圖面；透明像素獨立處理。這些命令會取代目前選區，不會修改圖片。

可使用「反選／擴張選區／收縮選區」調整像素選區。擴張及收縮半徑為 1–256 像素，採方形範圍計算，並裁在畫布內；接著可沿用複製、剪下、移動及選區效果。這是顏色比對，並非自動辨識物體。

### 圖文教學匯出

「編輯 → 儲存 → 匯出圖文教學（HTML）」可勾選目前開啟的圖片、上下調整順序，加入文件標題與各圖說明，再自行指定檔名。輸出為單一 HTML，圖片以 PNG 內嵌，可離線用瀏覽器開啟；原分頁仍保持可編輯，不會被標為已儲存。

每份最多 64 張，單頁底圖至多 128 MiB，單張編碼 PNG 至多 64 MiB，HTML 至多 128 MiB。匯出包含圖中可見內容，分享前請檢查。此命令產生靜態 HTML；PDF 輸出仍使用既有的圖片 PDF 功能。

### 複製貼上與畫布

Ctrl+A、Ctrl+C 複製整張合成圖，不會永久合併來源分頁的物件。貼到另一張後，整張圖成為可移動、縮放的圖片物件。在文字輸入框內，Ctrl+A 只選取文字。

一般圖片 Ctrl+V 保留原始像素及透明度，切到 100% 原尺寸顯示；畫布不足時向右／下擴充白底。超出視窗可捲動，貼上與擴充可一次復原。

游標在畫布內時，滾輪垂直捲動，Shift+滾輪水平捲動，Ctrl+滾輪以游標所在的圖片位置縮放；倍率依滾動量調整，範圍為 1–800%。靠近圖片邊緣時仍受捲動範圍限制。繪製、拖移、調整選區或畫布的過程中，滾輪不會改變視野；放開滑鼠完成操作後即可使用。

- 「新增圖片」以剪貼簿圖片寬高預填尺寸；沒有可用圖片時使用預設尺寸。建立的是空白圖，不會自動貼入像素。
- 一次拖入多張圖片，或使用「圖片拼接 → 插入多張圖片並編排」，設定欄數、間距及起點。圖片保留獨立物件，整批可一次復原。
- 「拼排已開啟圖片」在新分頁建立可編排的圖片物件，原分頁不變。
- 「圖片拼接 → 分割為圖片分頁」依欄數、列數，從左至右、由上而下產生 2–16 張 RAM 分頁；尺寸無法整除時仍會保留全部像素。分頁是目前合成圖的點陣副本，以 100% 顯示，原圖及可編輯物件不變，不會自動存檔。輸入合成圖與輸出像素緩衝合計上限為 512 MiB；其他物件、歷史與程序開銷另計。
- 拖曳畫布右側、下側或右下角控制點增加空間；向內拖不會裁掉內容。左／上留白及其他底色可由擴充畫布功能設定。
- 分頁可拖曳排序、重新命名及透過右側清單切換；名稱只在此次工作階段保留。

## 裁切、影像處理與比較

裁切框選後保留可調整範圍。拖控制點調整；拖選框內部會搬移選區像素，放開即定位，不需 Enter。「套用裁切」才移除選區外圍。

需要獨立編輯局部時，可使用「裁切 → 選區建立新圖片」或畫布右鍵的同名命令。它使用目前像素選區或已框好的裁切區，直接建立含標註合成結果的 RAM 分頁，不更動原圖或剪貼簿。新圖像素與來源合成緩衝合計上限為 512 MiB，需保留時請自行儲存。

「精準裁切／固定比例」可輸入 X/Y、寬高及比例寬高，例如 4:3、16:9；0/0 表示自由比例。啟用比例時依寬度計算高度，滑鼠調整也保持該比例。

「編輯 → 裁切 → 自動偵測裁切」可依透明外圍或左上角顏色尋找內容邊界。容差為 0–255：透明模式代表可忽略的透明度上限，顏色模式代表允許的色彩與透明度差異。偵測後只產生可微調的裁切框，按「套用裁切」才移除外圍；Esc 取消。單色或找不到可縮減外圍時維持原圖，已套用的裁切可一次復原，標註仍保留為可編輯物件。

影像工具包含縮放、旋轉、翻轉、移除帶狀區、調色、邊框、陰影、背景及浮水印。「任意角度旋轉」支援小數角度，可選擴大畫布或保留尺寸，以及透明或指定底色。需合併物件的操作會先提示，復原可回到原本可編輯狀態。

### 圖片物件可還原裁切

選取一個未分組、未鎖定的圖片物件，從「裁切」選擇「裁切圖片物件（拖曳邊緣）」，再拖曳外框控制點調整；放開滑鼠即完成一次可復原變更。也可用「圖片物件裁切範圍」輸入原始素材中的 X、Y、寬、高，或用「還原圖片物件裁切」恢復完整素材。這與裁掉整張畫布外圍的「套用裁切」分開。

原始素材仍保存在 RAM 與專案內，工具之間複製可編輯圖片物件也會保留素材；一般合成圖片只顯示裁切後內容。需要移除敏感原圖時，請分享一般合成圖片，不要分享保留原始素材的可編輯資料。

### 色彩處理

「編輯 → 效果」提供以下處理，也可透過自訂常用加入效果群組：

- 「Gamma 明暗校正」輸入 Gamma × 100，範圍 10–1000；100 為原樣，200 代表 Gamma 2.00、使中間色調變亮，低於 100 則變暗。
- 「復古褐色」以 0–100% 強度混合褐色效果，0% 保留原樣。
- 「替換顏色／轉透明」以 HEX 指定尋找及替換顏色；容差 0 表示 RGB 完全相符，其他值表示每個通道允許的最大差距。會處理範圍內所有相符像素，不限彼此相連。勾選「透明」會清除相符可見像素的色彩及透明度；它不是 AI 去背。
- 「縮減色階」設定每個 RGB 通道保留 2–256 個等距色階，256 為原樣。這是色彩量化，不會改成索引圖片，也不保證檔案變小。

可勾選「僅套用目前像素／裁切選區」限制處理範圍；未勾選則處理全圖。除指定轉透明外，以上處理會保留原有透明度。參數確認後先在背景產生預覽，按「套用」才更動圖片，取消不更動內容；像素沒有變化時不新增復原步驟。

圖片含可編輯標註時會先詢問是否合併，預設為「否」；同意並套用後可一次復原，還原原圖及可編輯物件。鎖定物件需先解除鎖定。處理有直接像素緩衝 512 MiB 上限，另計原圖、素材、歷史及程序開銷。要保留透明結果請選 PNG；JPG 等格式會合成白底。

效果預覽提供「顯示原圖」與「分割比較」，可拖曳分界滑桿比較處理前後；分界線只顯示於預覽，取消不會套用效果。

### 亮度與透視校正

「編輯 → 效果 → 直方圖／黑白點校正」顯示全圖亮度分布，略過全透明像素。輸入黑點及白點，黑點必須小於白點；區間內 RGB 線性展開到 0–255，區間外截斷。可套用至目前像素／裁切選區，預覽後按套用，或取消保留原圖；這與減少每色通道級數的「縮減色階」不同。

「編輯 → 旋轉 → 四角透視校正為新圖」輸入來源四角座標，順序為左上、右上、右下、左下，格式如 `10,5;900,20;880,600;15,580`，並指定輸出寬高。四角需在圖內並圍成凸四邊形。結果加入新的點陣圖片分頁，來源及可編輯標註保留；新頁以 100% 顯示，不自動存檔。直接處理的來源與輸出緩衝區上限為 512 MiB，不代表整個程式的記憶體上限。

### 圖片比較與復原

先開啟兩張圖片，再用「比較兩張圖片」選擇來源。提供並排、差異紅色標記與滑桿比較；預設依左上對齊、精確比較 RGBA 與尺寸；也可設定前述 RGB 容差及圖片 B 位移，不修改原圖。

復原／重做只保留在 RAM。清單以步數、尺寸與物件數識別快照；關閉後不保留，另存專案也不保存復原堆疊。工作區記憶體資訊區分保留儲存估計與程序取樣，兩者重疊、不可相加。

## 儲存、輸出與分享

「儲存／另存新檔／全部儲存」每次都顯示檔案對話框，必須自行指定檔名；全部儲存逐張詢問。首次使用 Windows Downloads；成功儲存圖片、圖片 PDF 或標註 SVG 後，會記住該資料夾，供其他圖片及下次啟動優先使用。資料夾已不存在時退回 Downloads。取消、圖片寫入失敗或儲存可編輯專案不會更新這個位置；取消也不清除未儲存狀態。

- JPG、PNG、BMP、靜態 GIF、PDF，以及多頁 PDF／列印。
- PNG 保留透明度；JPG、BMP、GIF、PDF 與列印合成白底。透明棋盤格只是編輯預覽，不輸出到圖片。
- GIF 為靜態 256 色圖片；PDF 為圖片頁，不是可編輯向量文件。列印預覽以 A4 為參考，實際紙張及方向依印表機對話框設定。
- `.sctproj` 內嵌原圖、素材與可編輯物件。目前格式 v13 可讀取 v1–v12 舊專案，舊程式不一定能讀取新格式；字型不內嵌，跨電腦需有相同字型。

分享敏感資訊時，請用實色遮蔽並輸出合成圖片。可編輯專案仍包含遮蔽前的來源，模糊及馬賽克也不等同安全移除資訊。

### 拖曳至其他應用程式與外部圖片匯入

「儲存」群組的「拖曳圖片至其他應用程式」會準備目前合成圖，請從開啟視窗內的拖曳按鈕，拖到接收圖片的應用程式。此功能提供 PNG／DIB 圖片資料，不會自動建立檔案或改寫剪貼簿；取消拖曳可再試一次。接收端若只接受檔案，請先自行另存圖片，再拖曳該檔案。實際支援情況依接收程式而定。

開啟或插入外部圖片檔時，會依 EXIF 方向校正，並透過 Windows WIC 將可用的內嵌 ICC 描述檔轉成 sRGB；無描述檔的圖片維持原像素，無法轉換的檔案會顯示錯誤。剪貼簿及專案素材不會再次套用這些外部檔案轉換，避免改變已編輯的內容。

## 快捷鍵與介面自訂

全域快捷鍵在「設定 → 全域快捷鍵」設定，可將 Print Screen 指定到全螢幕後按儲存；按取消不修改設定。若被 Windows 或其他程式占用，請先確認對應按鍵設定；本工具不修改系統鍵盤設定。

| 預設全域快捷鍵 | 動作 |
| --- | --- |
| Ctrl+Shift+1／X／3 | 全螢幕／矩形區域／指定視窗 |
| Ctrl+Shift+6／7 | 重複上次區域／游標所在螢幕 |

編輯器快捷鍵由「編輯 → 命令與快捷鍵 → 編輯快捷鍵」設定。可指定例如 Ctrl+K，使用 `-` 停用原綁定，或還原預設；有衝突時先停用占用者，再指定新命令。Ctrl+Shift+P 搜尋完整編輯命令。

其他常用操作：

| 操作 | 用途 |
| --- | --- |
| Ctrl+N／Ctrl+O／Ctrl+Shift+V | 新增／開啟／貼上為新圖 |
| Ctrl+S／Ctrl+Shift+S | 儲存／另存圖片 |
| Ctrl+G／Ctrl+Shift+G | 群組／解散 |
| Ctrl+L／Ctrl+Shift+L | 鎖定／解鎖 |
| Delete／PgUp／PgDn | 刪除物件／上移一層／下移一層 |
| Home／End | 選取物件移至最上層／最下層（畫布內） |
| Ctrl+0／Ctrl+1 | 符合視窗／原尺寸 |
| 滾輪／Shift+滾輪／Ctrl+滾輪 | 垂直捲動／水平捲動／縮放 |
| 中鍵拖曳／Space+左鍵拖曳 | 平移畫布 |

「常用 → 自訂常用」使用兩層選擇：先選功能群組，再選群組內命令，可調整順序。按儲存才套用；窄視窗透過「收合工具」使用放不下的項目。完整功能仍在最上方「編輯」。主視窗按鈕則由「設定 → 主頁功能選擇」獨立設定。

## 語系與可攜式設定

介面預設為**繁體中文**。首次啟動會在 EXE 旁建立 UTF-8 的 `SimpleCaptureTool.ini`、`lang_tw.ini`、`lang_en.ini`；請放在可寫入的資料夾。在「設定 → 一般設定 → 語系」選擇英文或其他可用語系，儲存後立即套用，之後啟動會沿用已儲存的選擇。Windows 原生檔案／字型／顏色對話框依作業系統語言顯示。

新增翻譯時，複製 `lang_en.ini` 為例如 `lang_ja.ini`，編輯 `[Language] Name` 及 `[Strings]` 等號右側文字，再重新開啟設定選擇。保留文字鍵、節名及檔案篩選器格式；缺漏文字依 Fallback 使用內建語言。

```ini
[Language]
Name=My translation
Fallback=en
[Strings]
Full=Full screen
Region=Rectangle region
Save=Save
```

程式不覆寫既有語系檔。取得新範本可在另一個空白、可寫入的資料夾啟動程式，再合併自己的翻譯。文字支援 `\n`、`\r`、`\t` 與 `\\`；每檔上限 1 MiB，每個值上限 4096 字元。

保留 `build`／`runtime` 相對位置以維持可攜性；圖片儲存由檔案對話框自行選擇。使用自訂絕對路徑時，搬到別台電腦後請確認路徑有效。

## 使用限制

- 受保護／DRM 畫面、鎖定桌面、UAC 安全桌面及部分 GPU／遠端桌面環境可能無法擷取。
- 視窗及捲動擷取結果受目標程式行為影響；分享前請檢查圖片。
- 自動捲動上限 100 次拼接；命名區域預設最多 20 組。
- 圖片編輯每邊上限 32768 像素、單張像素資料上限 512 MiB；專案內嵌解碼圖片合計上限 512 MiB，物件最多 10000 個、路徑點合計最多 1000000 個。
- 復原狀態最多 20 個，歷史儲存以約 256 MiB 為目標；大型圖片、合成及編碼另需工作記憶體，不能將上述數字當作整個程序的記憶體上限。
- 智慧橡皮擦適合近似單色背景，不保證修復複雜圖案；此工具不提供 OCR、QR、雲端上傳或持久截圖歷史。
