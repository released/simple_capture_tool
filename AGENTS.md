# AGENTS.md

## Workspace Layout And Safe Clean

Retain the documented advanced output profile. Canonical build/clean aliases preserve existing workflow. The clean helper is scoped to artifacts/obj and must preserve EXE/INI/unknowns inside it; runtime, dist, artifacts/debug and test evidence are not clean targets.


## Scope

Project-local rules for `simple_capture_tool`. `SPEC.md` is the product authority.

## Technical baseline

- Visual Studio 2022, MFC, C++17, x64.
- Minimum Windows version is Windows 10 1903.
- Keep `ui`, `core`, `services`, and `scripts` separated.
- UI text defaults to Traditional Chinese, supports live language switching through external UTF-8 catalogs, and must come from resources/localization, not direct literals in `src/ui`. Never overwrite existing user translations or translate editable document content.
- Screenshot work has priority. The user authorized completing all three scoped phases; FFmpeg is now used by recording only, after screenshot service and layout tests passed.
- Do not copy GPL code from ShareX or OBS into this MIT-targeted project.
- User configuration stays beside the executable; do not use the Registry.
- Output layout: build contains only the Release EXE/INIs; artifacts holds Debug, objects, dependency caches, evidence and audits; dist holds packages; runtime holds FFmpeg, counter and default captures. Centralize C++ paths in services/AppPaths; keep custom output paths and legacy FFmpeg fallback. Tests must not change the production counter.
- Heavy capture/encoding work must not run on the MFC UI thread.
- Capture handoff uses an active-only16ms poll timer with100ms housekeeping fallback; clear it before dispatch/chaining and on cancel/error/teardown, never leave it running at idle. Single rectangles crop frozen rows without pixel masks; full-screen matching geometry transfers the existing allocation, preserving recording and changed-geometry fallback. Batch the six editor combo lists/font initialization with redraw disabled, then restore before contextual visibility/layout; preserve all choices, DPI fonts and first-paint source fallback. Validate via CaptureLatency only unless another changed component needs coverage; private microbenchmarks/hidden UI timings are not hardware end-to-end latency.
- Keep the application's MTA usage cookie alive until all capture/recording workers have stopped; clear WinRT factory caches before releasing it.
- Editor objects remain separate from the source image. `.sctproj` includes embedded assets and must load transactionally with bounded lengths and checksums. Screenshot region confirmation must use the original frozen image, never a second desktop grab.
- Selection overlays compose frozen pixels, dimming, magnifier and toolbar offscreen and present once per paint; reuse the display buffer and preserve child-control clipping. Never expose intermediate desktop pixels during pointer movement.
- Images require an explicit save-dialog filename (Downloads initially, JPG by default); never restore automatic screenshot saving from legacy INIs. Build shutdown must be graceful and bounded, never force-kill or discard unsaved images.
- User-initiated image/workspace/main close and app exit discard unsaved RAM images without confirmation or autosave; main close-to-tray also closes all editors. Minimize/Hide retains documents. Do not apply this discard policy to guarded build exit, delete saved files, or publish pending clipboard results on close; join owned workers only during teardown.
- Editor File/Capture/Recording/Settings menus expose every MainFeatures command, including commands hidden on main Home, and forward to the live MainFrame settings owner with editor-owned modal dialogs. Block nested commands during those dialogs. Forwarded Exit may destroy the host: restore state only after validating the saved HWND and permanent object identity, never through an unconditionally dereferenced owner pointer. Preserve portable settings, language refresh and original IDs.
- Explicit editor Hide preserves RAM pages and uses a window-lifetime tray flag; tray restore/double-click returns to the same active page. Never confuse temporary capture hiding with user Hide, retain stale closed-window restore state, or change Close/Exit/build safety to implement Hide.
- Global capture hotkeys must route through the WM_HOTKEY window handler, not solely PreTranslateMessage. End native menus and defer capture until all menu loops unwind; execute once and do not queue modal-settings keystrokes. Print Screen is explicitly staged for Full screen and applied only by Save, with conflict rollback; never silently replace existing bindings or change Windows keyboard settings.
- Verify native window-message routing for mouse handlers, not just direct function calls. New capture sessions must receive their own first frame even when the caller reuses a populated image buffer.
- Clipboard encoding/allocation and image transforms belong to workers. Only publishing prebuilt clipboard handles happens on the UI thread.
- Ctrl+A selects the whole composed canvas immediately even during preview rendering; inside text editing it selects text. Cross-document paste must respect the pending copy intent and fail visibly instead of reading stale/superseded clipboard data. Keep transfer ordering on the UI thread and never block that thread waiting for encoding. Temporary document names are session labels only, not automatic save paths or persistent history.
- Raster Ctrl+V keeps original RGBA and Picture dimensions, extends only right/bottom with white space if needed and switches to100% top-left scrollable view. Expansion+insert is one undo step; preserve old pixels/objects/positions. Prepare/render on the worker and revision-check before swapping model/render together. Reject limits transactionally, never silently shrink. Keep editable-object clipboard offsets and file/drop Insert behavior unchanged; private paste reader auditing defaults empty and must never read/publish user clipboard images during isolated tests. Verify only PasteOriginal and other actually affected scopes.
- A text/annotation completion click is consumed, never reused as a new drawing gesture. Return focus to the canvas; keep failed text commits visible. Capture workspaces maximize, while RAM documents and undoable objects remain intact. Brush erasers do not show automatic resize handles. Text middle alignment, mosaic strength, eraser modes and cubic arrows use bounded project/private clipboard v5; retain v1-v4 project readers and v3/v4 clipboard readers, never mislabel new payloads with an older clipboard format. Mosaic slider release is one undo step, not per-move commits.
- Direct object clicks select without a new undo state; distinguish deliberate drawing drags and Alt force-draw. Selected arrow nodes move independently, including crossing; cubic arrows have exactly four controls and tangent-following heads. Ordinary eraser defaults to transparent, with palette-color mode; smart auto repair ignores transparent RGB and samples bounded opaque surroundings. Do not promise content-aware inpainting or flatten source objects when copying the canvas.
- Editor image origin is the canvas viewport top-left minus explicit pan/scroll offsets, never automatic centering. Preserve this shared origin for painting, hit tests, text and canvas expansion; view changes must not translate document pixels/objects.
- Frame the editable viewport with the shared2-logical-pixel slate border outside canvas_. Reserve its inset inside the existing viewport allocation and keep scrollbars outside; paint only four UI strips in the buffered painter before clipping image/objects. Never export/copy the frame, cover source pixels or translate document coordinates. Validate via CanvasFrame only (border pixels, white image, control separation, zoom/pan/hit tests and relevant native canvas-position/grip checks), not full canvas/image regression.
- Editor Home shortcuts use stable catalog keys and their own ordered INI field, independent from main-window HomeFeatures. Empty Home retains a fixed customization entry; original command tabs remain intact. Save through the main settings owner, refresh all editors after success only, and preserve the dedicated Home value when applying an older general-settings draft. Use the shared ribbon catalog, not a second command/translation mapping.
- New image resolves clipboard dimensions on the frame worker, then opens the existing blank-image form; missing/busy/invalid clipboard retains1280x720. Preserve the original modal owner across this async stage and reject destroyed/reused/hidden owners. Never paste clipboard pixels automatically. Home/More share the complete catalog including existing text, fill and eraser style commands; preserve custom order and original tabs. More dispatches validated WM_COMMAND so tools use their tool handler. Verification uses ImageHome only, private image/form/menu audits and hidden noactivate fixtures with a thread-local activation guard; no real clipboard images or visible dialogs.
- Home siblings collapse into one family at their first configured occurrence without rewriting stored shortcut keys. Split-button body repeats its current command; the down arrow/F4/Alt+Down opens a checked family menu. Cancel/stale results must not execute. Keep overflow submenus complete, use native command routing and retain original tabs. Menus/tooltip labels must use catalogs; last-used quick actions are session-local.
- Home is a single adaptive row:52..88 logical-pixel buttons,4px gaps, reserved overflow when needed, no second-row wrap or INI reorder. Compact Home/overflow use24px icon bands to reserve two caption lines; keep existing fonts,74px button height and14px dropdown strip. Other tabs retain original icon/layout sizes. Verify only affected RibbonMenu tests, including complete22-item Home, TW/EN96/120/144 simulated DPI, narrow/wide resize, native tab round trip, caption metrics and full overflow access.
- Pen drawing must not show automatic green object frames or select a just-created stroke; preserve consecutive freehand gestures and explicit selection/editing of old pen objects. Highlight remains rectangular by user choice. Keep the worker renderer and editable point/undo data; do not flatten strokes to hide controls.
- Editor selection guides use the shared pale gray dotted outline and hollow controls, not vivid green/solid blocks. Preserve hit targets and automatic selection behavior outside Pen; arrow endpoints are squares and curve controls are circles. Hollow interiors preserve underlying pixels, not a fully invisible frame or annotation-opacity change.
- For the approved PicPick alignment, track SPEC E01-E09/C01-C03/Q01 separately; do not claim parity merely because legacy tests pass. Open-document tabs are not persistent capture history. New document fields and clipboard formats require bounded, backward-compatible serialization and revision/identity checks.
- WebP uses unmodified, pinned official libwebp source and static libraries through setup_webp.ps1; retain its packaged license. New modal image previews borrow stable shared pixels and must finish their worker lifetime before returning those pixels to the editor. Automatic capture filenames use exclusive atomic promotion and a portable counter, never replace-existing writes.
- Runtime dependencies, private captures, audio, settings, and test evidence must not enter public source commits.

## Verification

- User-approved policy: select tests from the actual changed/affected components. Do not run the entire regression, all historical targeted suites, recording/hardware probes or full extracted-package tests after every modification. Full verification must be explicitly selected/requested; ordinary verification must specify its affected scope and report excluded suites. Canvas-only native tests must bypass unrelated core/printing/capture checks and use hidden, non-activating fixture windows without publishing the user's clipboard.
- Run `scripts\build_release.bat` after functional changes.
- Run the workspace clean-script verifier after modifying a clean script.
- clean_mfc.bat and compatible clean_build.bat/clean_build.ps1 delegate to clean_intermediates.ps1. Delete only allowlisted compiler files inside artifacts/obj, never the directory tree or EXE/INI/unknowns inside it. Preflight all ancestors/descendants for reparse points before deletion; retain tests/runtime/packages. Existing output relocation is explicit, no-overwrite and hash-verified via reorganize_outputs.ps1; never purge unknown build entries to satisfy the layout check.
- For MFC startup/layout changes, build and smoke-test Debug and Release.
- Native automated tests isolate only their own thread keyboard state and ignore unsolicited queued gestures; reset that state after modal test dialogs. Their default INI/counter belongs to artifacts/test-results, never the user's INI. Preserve normal production input handling; exception/assertion probes must exit with an error/log, not a CRT abort dialog. Keep native save auditors alive until queued save actions finish.
- Update `README.md`, `SELF_CHECK.md`, and `HANDOFF.md` when scope or behavior changes.
