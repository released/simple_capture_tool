## Architecture and state rules

- `src/ui`: window controls, selection overlays, commands, display synchronization.

- `src/services`: WGC/D3D11, WIC, config, annotation rasterization, audio, encoding and muxing.
- `scripts`: build, setup, verification, allowlist clean and portable packaging.
- UI strings are keyed in `services/StringCatalog.inc`, exposed by `Strings.*` and loaded by `LanguageService.*`; IDs are declared in `ui/UiSupport.h`. Language preparation precedes config commit; publication follows successful save. Stable interned translations protect concurrent worker readers and existing `const wchar_t*` consumers.
- The UI polls owned workers. Joins occur during worker/service destruction or inside recording worker cleanup, not on ordinary UI actions.
- Keep the process MTA usage reference alive across captures and clear WinRT factory caches before release.
- Recording state: Idle → Starting → Recording ↔ Paused → Finalizing → Completed/Failed → Idle.
- Video and audio share the same QPC timeline with paused spans subtracted; source silence is padded to preserve alignment.
- Final filenames appear only after successful encoding/muxing. Recovery files and encoder logs survive failures.
