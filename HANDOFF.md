## Lifetime / data contracts

- Keep the application MTA cookie until workers/COM objects stop; clear WinRT factories before release. Each new capture session must receive its own first frame.
- Use exact MFC ON_WM_* handler names and test native dispatch.
- Image rendering, encoding, transforms, clipboard preparation and capture belong to workers; UI only publishes prepared clipboard handles.
- Language values returned as const wchar_t* are interned for process lifetime. Prepare before saving settings, publish after successful config save. Never translate document or free-text controls by matching visible strings.
- Only application-tagged roots receive the private language-change message. Native file/font/color dialogs follow OS language.
- Capture auto-save exports original pixels, not later annotations. A separate editor save exports modifications. Dirty documents must not be silently marked saved by background original-image export.
- Desktop/region confirmation crops frozen pixels; selected-window confirmation obtains isolated WGC pixels.
- Output/project writes use unique partial files and atomic promotion. Project version 2 includes magnifier anchors; version 1 is readable.
- Projects retain original pixels behind redaction; share flattened exports, not sensitive projects. Fonts are referenced by name, not embedded.
- Language files use safe local lang_name.ini filenames, UTF-8, 1 MiB/file and 4096 characters/value; missing keys use declared fallback. Existing files are never rewritten or merged.
